# Architecture Decision Records

Lưu quyết định kiến trúc đã được chủ dự án xác nhận. Mỗi ADR nên có:
- Status: Proposed / Approved / Superseded.
- Context and problem.
- Decision.
- Alternatives considered.
- Consequences/trade-offs.
- Affected projects/data/contracts.
- Migration and rollback (if applicable).
- Date and approver.

AI may draft an ADR but must not mark it Approved without the owner's explicit decision.
